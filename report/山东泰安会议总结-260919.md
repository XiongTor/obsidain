# 1. Bao sheng Wang---橡树基因组渐渗与适应性进化研究

### 问题：
杂交渐渗如何促进物种多样化与适应性进化
### 材料方法： 
使用栓皮栎与麻栎的泛基因组（包含22个全基因组），同时检测SNP与SV（结构变异）
群体遗传学
### 知识要点：
两物种间完全平行的受选择模式在演化生物学上主要有三种潜在机制：
- 独立的趋同选择
- 不完全谱系分选导致的共享祖先多态性
- 种间基因流

全基因组选择扫描在 9 号染色体 ~14.0–14.5 Mb 区域检出一个极强烈的平行选择峰（Chr9-ERF 区域）， 全基因组系统树上，栓皮栎与麻栎各自单系分离；但在 Chr9-ERF 区域拓扑结构中，栓皮栎西部种群与麻栎西部种群紧密聚为一簇，直接==否定了独立趋同进化的假设==

等位基因剂量与 f4 统计量检验明确显示，栓皮栎西部种群在 ERF 区域显著富集了来自麻栎西部种群的衍生等位基因，证实该局部适应性单倍型是由麻栎向栓皮栎西部种群发生的**种间基因渐渗**所致（Liang et al., _MBE_ 2025）

在着丝粒区域，首次鉴定出一种主导的 146 bp  DNA 重复序列（命名为 QuCEN146），QuCEN146 的共享模式呈现出极大的染色体异质性。着丝粒区域重建的系统树完全不同于基于染色体臂 SNPs 所揭示的群体演化拓扑。这证明每条染色体的着丝粒经历着高度独立且快速的序列演化，其演化轨迹与染色体臂截然不同。同时在特定染色体的着丝粒区域，捕获到了明确的种间着丝粒渐渗，==表明这两个物种之间的渐渗并非近期杂交，而是古老杂交的产物==

# 3. Fernando HERNANDEZ---利用历史标本馆藏重建锈轴茅的入侵历史

内容偏向群体遗传学，主要通过标本馆材料与活体样本来证实北美历史上至少发生过两次独立的引入殖民事件
### 亮点：
通过时空基因组扫描在北部组和南部组中检出了显著的受选择离群位点，并证实了北美群体的开花时间与采样点地理纬度呈现强烈的非线性适应性共变，直接证实开花时序基因的快速自然选择使得*Microstegium vimineum*能够在短短数十年内精准匹配不同纬度的无霜期与日照长度，成为其征服北美的决定性演化驱动力

# 4. Harald SCHNEIDER---面对悖论——探索蕨类植物基因组的奇异现实

### 问题：
蕨类展现出极高的染色体基数 (n >= 40), 在遗传学上却表现出严格的二倍体减数分裂配对和单对基因分离
个人简单理解，这个悖论在说明，为什么一个具有如此多染色体的物种，最终表现出来的特性居然与一个简单的普通二倍体一样

螺旋上升假说：这种现象是由于多次反复的WGD时间造成的

### 材料方法：
新测序的高质量染色体水平蕨类基因组

### 知识要点：
**Schneider et al., 2026**：
- **种子植物（被子植物/裸子植物）**：基因组大小的扩张主要表现为**单条染色体物理长度的扩张**，而染色体数目（2n）变化幅度相对较小；
- **同形孢子蕨类与石松类**：基因组大小的扩张则主要表现为**染色体数目的扩增**，蕨类植物每条染色体的平均 DNA 含量与物理尺寸保持在相对狭窄的范围内，庞大的 DNA 最终被分配到数百上千条细小的染色体中。

推翻了螺旋上升假说：基因组共线性与 Ks 分析表明，尽管多数主要目在起源深处经历过一次全基因组加倍（WGD），但深层节点并未展现出连续多次 WGD 的普遍信号。

# 5. Huafeng WANG---植物系统学与东亚-北美间断分布生物地理学研究

### 问题：
以忍冬科及忍冬属为代表，破解北半球欧洲-东亚-北美（E-EAs-NAm）三地间断分布体系格局

### 材料方法：
忍冬科标本材料以及活体材料

### 知识要点:

构建了涵盖“超大样本标本库 + 靶向捕获基因组学 + 杂交网状演化模型 + 计算机视觉表型量化”的全链条研究体系：
基于忍冬科转录组序列自主开发了靶向捕获富集探针芯片（Hybrid-capture sequencing probes），捕获 713 个核基因单拷贝/低拷贝位点

澄清了系统发育关系，检测了ILS与杂交，进行了生物地理研究，相对来说较为基础

**LeafMachine**，对高分辨率数字化标本图像进行自动化叶片检测、边缘轮廓提取、长宽轴量化及叶面积计算的机器学习工具，在多个报告中有提及，可以尝试使用。

# 6. Kaichi HUANG---染色体倒位在物种适应与分化中的关键作用

### 问题：
在植物典型的局域适应过程中，染色体倒位是否必然伴随严重的有害突变累积代价？植物倒位的演化动态是否遵循全新的理论范式？

### 材料方法：
北美菊科向日葵属野生植物
群体遗传学

### 知识要点：
与经典动物模型预测完全相反，向日葵倒位区段内有害突变比例并没有出现任何异常升高
