# 大纲
### 1. 如何快速将本地代码库上传到GitHub云端库中
- 通过AI agent工具快速实现---首次上传非常简单便携。后续持续维护，每次要和AI对话的话，非常不方便
- 本地终端实现，后使用VS code长期维护
### 2. 基于VS code的本地代码维护，日常使用
- VS code功能简单介绍，可直接运行python, R(或使用Positron). 同时支持SSH远程链接服务器
- 脚本的基本格式，日常如何方便管理
- README.md文件的书写，自己手动编写或在日常维护的基础上使用AI总结
- Git的日常管理，涉及多个库以及主分支的时候，要注意上传的时候具体上传到哪个库的哪个分支，防止库管理混乱，导致数据被覆盖
- 版本控制，自己查看版本号，或直接通过AI阅读git库辅助回退版本
