# 1. Order of Recursive of calls 理解递归函数调用的顺序
当进行了一次**函数调用的时候，必须等到它返回值之后，才能进行下一步操作**
在下列例子中，cascade(n // 10)之后的print(n)是在所有的cascade(n // 10)执行完之后再次执行
同样的这个函数中没有`return`所有最后的一个print(n)会在所有的栈帧中依次被打印一遍，从最新的到最老的

下列两个函数，哪一个更优
一般来讲，右侧更加简洁，所以左侧更优
但有些时候，左侧的可读性更好，它符合我们对于这个递归函数的认知，知道在什么情况下打印出哪些参数
==两个函数各有优势，大多数情况下，代码是写给人读的，只是偶尔在计算机中执行，如果从这个角度出发，或许左侧的结果更好==
