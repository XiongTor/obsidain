# 背景介绍：一开始的背景是在一个封闭的建筑内部，不清楚其构造与原理，其最大的特点就是如酒店一般紧密排列的房间，同时不同的房间内部也可以互通，还有长长的走廊。在建筑内的大部分房间以及走廊上都是漆黑一片的，伸手不见五指。因此我似乎获得了一种能力，在某些不确定的时候，我能通过自己的肉眼达到类似热成像一样的视觉效果。但是这种能力也不是常驻在我身上的。只能在某些特定的时候突然触发。
# 显然，一般这种设定下必定是有怪物的，这次梦里怪物似乎不止一只，而是一个种群，有点类似吸血鬼的设定，人形怪物但是智商不高，且数量不多。因此在这栋大型建筑内其实很少会碰到这种怪物，但是最麻烦的地方在于，怪物也拥有热成像式的能力，能够透过普通的墙壁来锁定我们的位置（并不是所有的墙壁都能透过），并且在关键的节点处，必定会存在至少一只这种怪物在游荡，应该就是单纯为了防止有人逃出这栋建筑。因此又引出了我的第二个能力，梦里经常会出现的第三人称视角，我在某些时候会具备一定的预知能力，预知能力会通过第三人称视角的形式，让我同时观察到我本人和怪物的相对位置，以及各自的热成像视角视线。同时整栋建筑也并非普通的建筑，主要特点就是移动的方式不仅仅局限于物理上纯靠双腿的移动，某些位置似乎存在特定的传送点，可以通过传送到达特定的位置。

# 梦里的大部分场景已经没有什么印象了，只记得我最开始是和一个伙伴一起想要逃离这栋建筑到达下一个地点。这个伙伴一开始似乎是人类男性，后面不知不觉似乎就转变为了兽人种的女性，形象参考方舟的亚叶的形象，这是我梦醒后的第一印象。
# 我和亚叶似乎已经在这栋建筑内探索了很长的一段时间，我们已经到达了最后的关卡，是在类似酒店阁楼的一处空间中，我们通过回型的楼梯走到阁楼上方，有一个紧闭的大门，上面一直有一个规律性的闪烁轮换不同颜色的条状显示屏，大小大概只有我的两根手指并排的大小。梦里意识到这个显示屏不同的颜色代表着门后不同的状态，绿色是安全，红色是怪物正在游荡，还有一个浅绿色的状态，似乎代表着完全不确定门后是什么状态。然而目前最要紧的问题是我们没有这个门的钥匙。亚叶提到，刚刚在阁楼的下方，有一个锁着的柜子，里面可能会有打开这扇门的钥匙。于是我们又开始往下走，走到一半，注意到阁楼角落里的传送阵突然亮起，我们开始警觉起来，害怕是怪物传动到了这里，索性这种事情并没有发生。走出来的是我的一位多年未见的朋友，但是与印象中不同的是，他似乎强壮了许多，肌肉线条十分明显，目前也不清楚他到底经历了什么，目前是否可信。亚叶松了口气，开始走到柜子前，但是柜子也是上锁的，不过是这种🔒，老朋友并不知道我们为什么要打开这个锁，但是他提议到，没有钥匙打开的话，不妨试试直接破坏柜子拿到里面的东西。亚叶试了试，但是没能成功，于是便走到一边和老朋友在交谈。在他们交谈的时候，我也上前尝试了一下。找到一个类似撬棍的工具，我直接撬开了柜子，动静很大。此时传送阵又亮起，我们所有人都是一阵警觉，索性此次并不是怪物，又是两位非人类种的女性。反应过来后，趁着所有人都没注意的时候，我快速扫视了一下柜子里的物品，锁定到钥匙后立马拿了下来并放到自己的口袋中。这时老朋友也已经过来了，问我柜子里有什么好东西吗，我假装拿了一卷胶带和一个绷带，说这些物品还不错，剩下的东西可以随你们拿了。然后趁着刚刚传动来的人还在适应中，快速走到亚叶的面前，说钥匙已经拿到手了，这里的人不知道是非可信，我们赶紧上去试试能不能打开楼顶的大门。
# 牵起亚叶的手，我们快速走到了楼顶处，开始将钥匙插进门锁里，发现真的打开了，于是我顺手打开了门，但是突然意识到，此时的灯是浅绿色的，心中大惊，又迅速关上了大门，所幸没有怪物在门后，我们吓出了一身冷汗。刚刚关门的动静太大，一下子所有人都被吸引到了我们这边。没办法我只得向他们解释事情的原委，大家似乎都是值得信任的人，没有任何人有异常的举动，表示待会一切听从安排。
# 等到灯变成绿色后，我再次小心的打开了大门，门后又是一片漆黑的走廊，走廊很宽，感觉有5.6米宽的样子，这样似乎已经不能称之为走廊了，并且走廊是和我们开门的方向是垂直交叉的，我们似乎在一排门的这边，对面又是许许多多的门。一刻也不敢怠慢，我们快速跑到对面，对面的门也是上锁了的，我想到刚刚的钥匙有两根，于是我赶紧拿起另一个钥匙，开始摸索着插向钥匙孔，并嘱咐亚叶赶紧给我打光，我感觉到刚刚出来的门上的显示屏马上就要转变为红色了。时间才过去了几秒，亚科的手电还未打亮，我突然感觉到一阵压迫感，很明显，怪物正在朝我们这边过来，我已经顾不上等亚叶打光了。一通摸索乱插，终于插进钥匙打开了门，快速的让所有的人进到房间里面。就在刚刚关上房间门的一刻，我看到对面门上的屏幕转变为了红色。 
# 所有人进到房间后都瘫倒在地，刚刚有形的压力让大家都感到十分恐慌，不过，我们终于走到了这一步，房间内还有一扇门，根据我的记忆，这扇门就是这栋房间的最后一扇门，穿过它我们就能逃离这栋建筑了。就在此时，我的视角突然转向了第三人称视角，我看到了怪物正在我们刚刚进来的门后，用它的热成像能力扫向我们，我的热成像能力也发动了，也在扫向它。很明显，这是我的预知能力发动了，我赶紧收回视角，告诉大家快速起身，再不走的话，马上就要被追上锁定了。于是我又抓起亚叶和另一个非人类种的女孩快速跑到最后一扇门前，一脚踢开跨了进去，其他人也随后踉跄起身跑了过来。
# 梦里的下一个记忆点似乎已经是逃离建筑后的一段时间了。建筑里的最后一扇门似乎是一个传送阵，我们直接被传送到了一个新的大陆，怪物最后确实破门而入了，但是它似乎无法离开那栋建筑，并没有跟随过来。
# 我们似乎在这个新大陆已经冒险过一段时间了，途中又新加入了一个带着兜帽的，有着狼耳的男孩，我和亚叶以及最后逃离建筑时牵着的另一个女孩的关系也越来越好(姑且叫小A吧)，新加入的男孩不知为何也十分信任我。我们现在是在一个平原上，四周的远处都是很高的高山围成的屏障，我们应该是在一个平原盆地中，旁边我的左侧是一个大风车在呼呼的转动，右侧有一片明显高出4米左右的山坡，山坡上是一片森林，哪里似乎就是我们的目的地。虽然已经忘记了是怎么回事，但是大家看到那片森林似乎都很兴奋。小A高兴的冲我笑了笑，然后快速的跑上了那片森林。亚叶这时候凑了过来，冲我笑了笑，说到“那个女孩现在似乎已经离不开你了呢”，然后也快步走向森林。在梦里，我明显是对亚叶有更多好感的，因此我望着亚叶的背影问她"哪你呢"。亚科没有回复我，只是轻快的往前走去，小男孩走了过来，和一同往前，但是略微领先我1m左右的距离。男孩的名字叫亚舍，不知为何脑中突然就涌入了这个信息，亚舍在前方走着，突然，它的头上凭空出现了一个绳套，似乎是即将落下要将他套牢吊起，我惊呼出声。然后梦醒了。暂无后续了。
