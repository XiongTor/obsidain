# **蔷薇科网状演化驱动下的核质冲突解构**

# 一. 科学问题与研究目的
1. 蔷薇科内==核质冲突==的**宏观模式**如何？这些冲突在不同亚科/族水平上的分布是否具有**不均匀性**？
2. ==核质冲突==与核质的序列属性之间的关系，就是是核质序列的哪部分属性的不一致导致了核质系统发育树之间的冲突？
3. 核基因==物种树与基因树的冲突==情况如何。这些冲突在不同亚科/族水平上的分布是否具有**不均匀性**？与核质冲突是否相互呼应？
4. 在==生物学因素==上，ILS和IH谁更加严重，具体又是发生在哪些类群中？
5. ==非生物学因素==在这种偏差中到底占据了多大的比重？
6. 到底哪些基因中渐渗比较严重，而==哪些基因==中ILS比较严重？这些基因中又是哪些物种间的发生的IH/ILS
7. 这些IH/ILS影响严重的基因具有什么特征？
8. 如果真实ILS和IH导致了不一致，==如何证明==？进一步进行数据筛选后，能够减弱这种核质和基因树彼此之间的冲突情况？

# 二. 具体需要进行的分析
### 1. 反映核质冲突
1. **冲突衡量**：利用三套数据集，进行 cophylo 可视化对比，并量化计算 RF 距离和 Path 距离。此外，可以考虑使用**AU test**进行检测，说明各自的拓扑都是各自序列数据的最优解，不存在说彼此的拓扑可以互为替代的可能。
2. **冲突的类群异质性**：将上述冲突指标细化至亚科（Subfamily）和族（Tribe）水平，识别蔷薇科内冲突最剧烈的“进化热点”类群。
3. **序列属性关联分析（新增）**：
  - 统计核/质基因在长度、GC含量、**简约信息位点（PIS）**等属性上的差异。
  - 筛选 PIS 含量与质体基因接近的核基因子集，观察其 RF 距离的动态变化。
  - **目的**：初步判定核质冲突在序列上究竟是由何种属性差异导致的

### 2. 基因树与物种树冲突
- phyparts饼图，densitree绘制基因树背景，初步说明基因树冲突存在
- MDS分析，反映整体基因树的聚合程度，是大都聚集到一起还是均匀的分布开来。
- gcf，scf值计算，QS计算QC,QD,QF值，ICA,IC值计算。目的是深入的量化物种树和基因树在各个节点的冲突情况。初步表征ILS/IH的存在可能。基于基因树统计的节点的不一致，后面的分析大都是基于quartet的不一致。

### 3. ILS，IH，GTEE检测
- phytop分析，进行IH，ILS水平的初步探究。
- MSCquartet分析，主要查看能否检测出杂交信号，同时查看在不同α阈值的情况下杂交的情况如何，同时判断杂交到底发生在哪些gene的哪些类群之中，同时统计ILS和IH各自占据的比例。
- Dsuite分析，查看渐渗主要发生在哪些类群中，并期望通过SNP和gene分组文件定位到具体的类群和gene。
- QuIBL分析，主要查看ILS和渐渗谁更加严重。并尝试定位到具体基因和类群。
- ILS_IH_GTEE分析，主要查看ILS和渐渗谁更加严重，并通过GTEE的值的大小判断分析流程是否有问题。此步骤最终可以不用柱状图来展示三者的各自贡献。而尝试使用线性回归方程来量化GTEE的占比。或者说GTEE在某种程度上可能是ILS的背景噪音。
- splittree，计算网状树，查看蔷薇科内的网状结构是否存在，且主要集中在哪些类群。
- Phylonetwork，通过计算族水平的网状树来判断整个蔷薇科的网状结构。可以考虑使用高中低三个层析的渐渗强度物种来进行检测。

### 4. 渐渗与 ILS 的细化鉴定
1. 鉴定的出高ILS贡献和高GTEE贡献基因有什么特征，在序列属性上是怎样的。另外，在两套数据集中，它们是否存在重合。
2. 如何确认检验出的高IH/ILS基因就是正确的呢？
   - 依靠两套核基因数据集和多种判定方法来落实结果
3. 如何确认就是ILS/IH导致的核质冲突和基因树之间的冲突？去除高ILS，高IH水平的序列，重建树后判断：
  - 核质冲突是否有所改善
  - 基因树冲突是否有所改善。
  - 网状结构是否有所改善。

# 三. 思考
### 1. 对于后续的核质冲突调和，主要措施是挑选去潜在的渐渗基因和ILS严重的基因，在大的方向上可以考虑以下几点：
- 核水平，基因树与物种树，挑选出渐渗基因后查看，新的基因树与物种树之间是否差异减小了
- 质体水平同理
- 查看新的质体树和基因树之间是否冲突减少了
> 与物种树之间差异大的基因树，是否就是渐渗基因。这种筛选是去掉整个基因还是针对基因中的部分物种进行去除，渐渗应该是物种中的部分基因片段发生了交换改变，应该削减的是这个片段，或者说这个物种的被污染的这个基因，而不是直接把所有物种的这个基因全部去除。

针对这一步，目前想法有所改变，在此数据集中，我们的主要任务应该不是去除这些渐渗或者说ILS基因，因为目前的数据集太小，无论是353基因集还是orthofinder基因集，包含的基因数量还是偏少，如果盲目的去除，可能会导致数据量的大幅下降，从而影响最终系统发育树的稳定性。
所以目前的主要重心还是放在细化鉴定上，主要体现在以下的几个方面：
- 衡量某一个基因中，包含有多少被鉴定为IH的四联体，以及有多少被鉴定为ILS的四连体。
- 衡量特定的物种间，有多少基因或者说有哪些基因支持其IH或ILS现象。
- 针对每一个基因赋予其一个IH或者ILS比例的可能值。
- 比较ags353和orthofinder基因中，都被判断为渐渗的基因是否是同一个基因，以及都被判断为ILS的基因是否为同一个基因。
在此基础上，结合目标基因的序列长度，判断是否真是由于ILS引起的，还是由于序列过短等非生物学因素导致的。

> 2026.02.05    关于此问题，目前似乎不用过于担心数据集的大小带来的误差。在方法上，可以随机去除部分数据或者挑选高低两套相反的数据来彼此印证。在理论上，有相关研究证明，数据集的大小对于拓扑的影响没有想象中严重，不过在真正的类群研究中还是要考虑到自己的数据集和类群特性来具体判断。[@Using all gene families vastly expands data available for phylogenomic inference_2022](references/@Using%20all%20gene%20families%20vastly%20expands%20data%20available%20for%20phylogenomic%20inference_2022.md)

### 2. 针对MSCquartet方法中，继续深化中需要的问题
  1）首先需要考虑的问题就是T1和T3两种不同的模型之间的差异，如何去解释与调和
  2）不同水平的α阈值和β阈值，最终挑选出来的高IH/ILS基因之间存在差异，如何去解释和继续分析这种差异。
  3）每个基因发生渐渗的物种对都不一致，如何去继续探讨这种情况

### 3. 目前最大的问题是，针对系统误差与生物学因素的探讨还是不够充分
