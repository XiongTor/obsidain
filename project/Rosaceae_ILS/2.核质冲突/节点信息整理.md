# 为什么我们需要关注节点?
> 计算了下列如此多的参数，有必要性吗，以及为什么要计算这些参数。理论上我们只需要知道不同节点的所有可能拓扑的数量占比就够了，自然就能直接判别出其可靠性与ILS，IH的可能性

### 要回答这个问题，我想我们需要从节点所能够包含的信息来说起（仅限于二歧物种树的讨论）
### 1） 稳固拓扑结构
  如果不存在节点，那么系统发育树将会以“梳子”的结构存在，从而丧失其分类作用。所以节点最重要的功能就是稳固拓扑，使其具有一定的分辨率
  那么节点值的第一个作用就是判断该节点是否稳固，即是否可以在多次运算中呈现可重复的结构，以及其本身是否具有足够的信息含量。
  这一部分，我们可以通过**BS和QI值**来衡量
  
  其中QI值可以这样理解：
  - 是基于quartet来计算的
  - 帮助研究者确定低支持度究竟是因为数据太少（QI 低），还是因为分支本身存在复杂冲突（QI 高但 QC 低）
  - **QI = 1**：表示 100% 的采样重复都提供了足以区分不同拓扑结构的强有力信息
  - **QI 值低**：意味着许多采样重复因为分子数据不足、对齐稀疏或信号太弱而无法得出确定的结论，这些重复会被标记为“未信息化”（uninformative）并单独统计
  >信息化：只有当最优拓扑结构的似然值比次优拓扑结构高出一定的阈值（cutoff）时，该次采样才被视为“信息化”的

### 2）主拓扑的支持程度
  判断物种树展示的这个拓扑在该节点到底获得了多大的支持
  从基因树或者说quartet树的层面，可以从**gcf和QC以及ICA和IC值**来判断
  从序列的角度，可以从**scf值**来判断

### 3）替代拓扑的分布频率------暗示ILS，IH
主要分为两点，只存在一个主要的替代拓扑和存在多个分布频率类似的拓扑。但是要分不同的前提，其最终的解释也可能不一样
前提一：主拓扑占据了绝大部分比例
- 存在一个较强的替代拓扑
- 所有替代拓扑分布频率相当
前提二：主拓扑占据了适中的比例，即仍然是多树，但不是最多，例如40%的主，两个30%的次要拓扑
- 存在一个较强的替代拓扑
- 所有替代拓扑分布频率相当
前提三：某一个替代拓扑占据了较大部分比例，主拓扑反而占据比例较小
- 存在多个强于主拓扑的替代拓扑
- 仅有一个强于主拓扑的替代拓扑

**主要通过QD值和ICA，IC值来判断**

# 1.节点信息收集
- ### gcf : 
      (Gene Concordance Factor，基因一致性因子)指在所有单独构建的基因树中，有多少比例的基因树支持物种树上的某一个特定分支（节点）。它反映了**基因层面**的拓扑一致性。
- ### scf
      指在多序列比对矩阵中，有多少比例的独立DNA变异位点（单核苷酸多态性）支持该分支。它反映了**信息位点层面**的支持度。
- ### QD
	  (Quartet Differential，四分体差异/冲突不对称性)：取值 [0, 1]。如果不支持主树的四分体，在另外两种备选拓扑中分布**不均匀**（偏斜，QD值低），通常暗示存在**基因流/杂交/渐渗**；如果分布均匀（QD值接近1），则更可能是 ILS 造成的随机噪音。
- ### QC
     (Quartet Concordance，四分体一致性)：取值 [-1, 1]。衡量抽样四分体中有多少支持主拓扑。1表示主拓扑占据绝对优势
- ### QI
     (Quartet Informativeness，四分体信息量)：取值 [0, 1]。评估这些四分体是否具有足够的系统发育信号（区分拓扑的能力）
- ### ICA
     (Internode Certainty All, 所有内部节点确定度): **计算主拓扑的频率与所有占比超过5%的冲突拓扑频率总和之间的比值
- ### IC
     (Internode Certainty, 内部节点确定度)： **计算主拓扑的频率，与最强力反对这个分支的拓扑频率之间的比值**
- ### BS
     (Bootstrap value)  自举支持率
- ### Branch length
     枝长
