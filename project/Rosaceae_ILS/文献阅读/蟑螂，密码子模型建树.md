# 1. 材料与方法

## 可使用的工具

- **treedist**，可以用于检测物种树与基因树之间的==**RF距离**==和==**path distance**==
但是需要注意的是，RF值的大小可能会受到哪些无赖类群(rogue taxa)的影响，即那些在基因树中位置频繁变动的类群，这部分类群的加入通常会导致RF距离的变大。  
path distance相对来说对于无赖类群的干扰要轻一点，但是==**RF距离**==和==**path distance**==可能会得到不同的结果，所以建议选择**两种方法结论一致**的结果。

- Z-Test，通过R包BSDA来实现
