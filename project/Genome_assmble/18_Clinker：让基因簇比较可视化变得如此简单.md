### 18.<font style="color:rgba(0, 0, 0, 0.9);">Clinker：让基因簇比较可视化变得如此简单</font>
学习链接：[https://mp.weixin.qq.com/s/2_u94sGjnC2txpDVIAM9Tw](https://mp.weixin.qq.com/s/2_u94sGjnC2txpDVIAM9Tw)

<font style="color:rgb(63, 63, 63);background-color:rgb(247, 247, 247);">Clinker是一个自动生成发表级基因簇比较图的强大工具，现在更可以在CAGECAT webserver上直接使用，无需安装！支持GenBank和GFF3文件格式，专为生物合成基因簇可视化而设计。</font>

**<font style="color:rgb(15, 76, 129);">官方网站</font>**<font style="color:rgb(63, 63, 63);">：</font>[https://cagecat.bioinformatics.nl](https://cagecat.bioinformatics.nl)

**<font style="color:rgb(15, 76, 129);">使用步骤</font>**<font style="color:rgb(63, 63, 63);">：</font>

+ <font style="color:rgb(63, 63, 63);">访问CAGECAT网站：</font>[https://cagecat.bioinformatics.nl](https://cagecat.bioinformatics.nl)
+ <font style="color:rgb(63, 63, 63);">点击"Analyze"按钮</font>
+ <font style="color:rgb(63, 63, 63);">选择"clinker"或"cblaster"工具</font>
+ <font style="color:rgb(63, 63, 63);">点击"Start"开始</font>
+ <font style="color:rgb(63, 63, 63);">上传基因簇文件</font>
+ <font style="color:rgb(63, 63, 63);">设置分析参数</font>
+ <font style="color:rgb(63, 63, 63);">查看交互式结果</font>
