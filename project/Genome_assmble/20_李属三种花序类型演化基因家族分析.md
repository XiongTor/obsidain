### 20.李属三种花序类型演化基因家族分析
#### 通过功能富集寻找收缩和扩张的基因家族，比较每个花序类型特异的基因家族，查看功能富集
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/54922767/1764403135085-182457d1-2d14-4862-b551-3067d3768e91.png)

 把你的 **Orthofinder 输出（每物种的基因家族计数）** + **物种树（含分支长度，最好为超时树 / ultrametric）** 作为输入，用 **基因家族演化模型（CAFE / BadiRate）** 找到在某些分支/类群（对应单花、伞房、总状）上显著扩张或收缩的家族 → 对这些家族做功能注释/富集（GO/KEGG/InterPro）→ 与花序表型做比较与统计验证（phylogenetic ANOVA / PGLS / ancestral mapping）→ 对重要候选家族（如 MADS-box）做深入分析（拷贝数、序列进化、基因树、同源/共线性、表达）。  



###### 1) 准备并清理数据（必做）
+ 文件来自 Orthofinder：`Orthogroups.GeneCount.tsv`（每个 orthogroup 每个物种的基因数）。
+ 过滤建议：
    - 去掉在所有物种中都为 0 的家族（无意义）。
    - 去掉完全单拷贝的家族（不会显示扩张/收缩信号，但视情况保留）。
    - 保留在 ≥ N 个物种中出现的家族（例如 N = 3 或 N = 5），以减少噪音。
+ 输出为 CAFE 可读的 family 文件格式（下面给转换示例）。

**示例转换（bash + awk）**  
（假设 `Orthogroups.GeneCount.tsv` 有第一列 `Orthogroup`，后面是物种列）

```bash
# 生成 CAFE family 文件头：第一列 FamilyID 后面是 species names
awk 'OFS="\t" {$NF=""; print}' Orthogroups.GeneCount.tsv > tmp && \
awk '{print "(null)" "\t" $0}' tmp > cafe.input.tsv && \
sed -i '1s/(null)/Desc/' cafe.input.tsv && \
rm tmp

```

###### 2) 构建/准备物种树（ultrametric）
+ CAFE 需要带 branch lengths 的树；若使用基于核基因或 Angiosperms353 的树，**把树转换为 ultrametric（时间尺度）**更合适，因为 CAFE 假设时间尺度上的演化率。
+ 可用 R 的 `ape::chronos()` 或 `treePL` / `r8s`。下面给 R 示例。

**R：把普通树变 ultrametric**

```plain
library(ape)
tree <- read.tree("species_tree.nwk")
# 方法1：chronos（penalized likelihood）
ultra <- chronos(tree, lambda=1)  # 你可以调 lambda
write.tree(ultra, file="species_tree_ultrametric.nwk")
```

（如果你的树是已校准时间树，直接用即可。）：mcmctree估算的时间树，R*100：Prunus.nw.ultra.tre

---

###### 3) 用 CAFE 做基因家族扩张/收缩检测（推荐）
+ CAFE 会给每个家族在每个节点上的 p-value，标记显著扩张或收缩（基于基因家族大小模型）。
+ 需要：family 文件 + ultrametric tree。
+ 关键参数：lambda（演化速率），可以设为不同类群不同 lambda（例如单花类群 vs 伞房 vs 总状）。
+ 注意对多重检验使用 FDR 校正（CAFE 报告通常已经给 family-level p-values，需要自己做 FDR）。

**如何检测“在某一类群特异”**

+ 方案 A：在物种树上把单花/伞房/总状分别设为 clade（子树），然后在 CAFE 中允许不同 clade 有不同 lambda，看哪些 families 在该 clade 的节点显示显著 p-value。
+ 方案 B：用 CAFE 输出的 per-node expansion/contraction, 选出发生在对应类群分支（或最近共同祖先节点）上的 families。

---

###### 4) 功能注释与富集（GO / KEGG / InterPro）
+ 目标：把显著扩张/收缩的 families（基因 ID 列表）做富集分析，检查是否富集了 MADS-box、激素通路、发育相关 GO/KEGG。
+ 推荐流程：
    1. 用 **eggNOG-mapper** 或 **InterProScan** 对所有基因做注释，得到：GO、KEGG、蛋白家族 (PFAM/InterPro) 注释与基因名映射（非常重要）。
        * eggNOG-mapper 命令示例（在 cluster 环境）：

```plain
emapper.py -i all_proteins.fa -o emapper_out --cpu 20
```

```plain
2. 从 Orthogroups 抽出家族对应的基因名单（例如某 family 的所有成员 ID），再用注释文件把 gene IDs 转成 GO/KO/Pfam 等。
3. 用 `clusterProfiler`（R）或 `topGO` 做 GO 富集；用 `clusterProfiler::enrichKEGG` 或 KOBAS 做 KEGG。
```

**R（clusterProfiler）示例**

```plain
library(clusterProfiler)
library(org.At.tair.db) # 如果你用模式植物；对非模式物种须先做 ID 映射
# 假设 geneList 是显著家族中的基因 ID 向量， universe 是背景基因向量
ego <- enrichGO(gene         = geneList,
                universe     = universe,
                OrgDb        = your_orgdb, # 若无可用 mapping，用自定义 TERM->GENE 列表
                keyType      = "CUSTOM",
                ont          = "BP",
                pAdjustMethod = "BH",
                qvalueCutoff = 0.05)
```

**注意**：非模式植物的 KEGG 通常需要先把基因映射到 KO id（eggNOG / KofamScan），再用 `enrichKEGG`。

---

###### 5) 比较三类花序的特异性家族（核心）
+ 得到三组家族：`Fam_solitary`、`Fam_corymb`、`Fam_raceme`（单花/伞房/总状特异扩张或收缩）。
+ 做交集/差集分析（Venn / UpSet），看哪些家族是**独有**于某类花序，哪些是**共有**。
+ 对独有和共有家族分别做富集比较（可以发现比如 MADS-box 主要在总状独有家族中富集，则更有力）。

**可视化：UpSet 或 Venn + 热图**

+ 用 `UpSetR` 或 `ComplexUpset` 绘制交集。
+ 用 `pheatmap` 或 `ggtree + gheatmap` 在树上显示每个物种的家族大小矩阵（直观看拷贝数变化）。

---

###### 6) 统计检验：花序类型与家族大小的关联
+ 你需要证明：某些家族大小与花序类型有统计学上的相关性（重要一步，不能只靠富集）。
+ 常用方法：
    1. **phylogenetic ANOVA**（`phytools::phylANOVA`）
        * 把家族大小作为响应变量，花序类型（categorical）为组别，使用物种树做 phylogenetic correction。
    2. **PGLS（phylogenetic generalized least squares）**（`nlme` + `ape`）
        * 对连续变量（家族大小）与二元/类别性表型建模。
    3. **Ancestral state reconstruction + 重构节点上家族大小变化比对**
        * `ace()`（ape）或 `phytools` 的连续性 trait 重建，检验在花序转变的节点是否伴随家族大小变化。

**R：phylogenetic ANOVA 示例**

```plain
library(phytools)
# tree: phylo object
# trait: named vector of gene family sizes
# group: named factor of flower type (solitary/corymb/raceme)
res <- phylANOVA(tree, group, trait, nsim=1000)
print(res)
```

---

###### 7) 候选家族（如 MADS-box）深入分析
当 MADS-box 被指出显著时，做下列验证与深入工作：

+ **拷贝数统计与比较表格**：每个物种 MADS-box 的基因计数（表格 + 热图）。
+ **序列筛选**：把所有 MADS-box 蛋白序列抽出。
+ **多序列比对 + 基因树**：用 MAFFT + IQ-TREE / RAxML 构建家族树，检验复制事件（谱系特异复制 vs 全部复制）。
+ **同源/共线性分析（synteny）**：在大叶桂樱中看 MADS-box 家族是否来自 WGD/局部重复（MCScanX 等）。
+ **表达证据**（如果有转录组）：检查不同花器官或发育阶段里 MADS-box 的表达模式，支持其功能角色。
+ **选择压力分析**（Ka/Ks）：检验某些拷贝是否受正选择或中性衰减。

---

###### 8) 将所有证据综合写成结论段
+ 结构化写法示例（论文 Results/Discussion）：
    - “基于全基因组基因家族演化分析（Orthofinder + CAFE），我们在总状类群中检测到若干家族显著收缩/扩张；这些家族在功能注释上显著富集于与花发育（MADS-box 转录因子）相关的 GO/KEGG 分类。phylogenetic ANOVA 显示，MADS-box 家族大小与花序类型显著关联（p = X，FDR 校正后 q = Y）。进一步的基因树与共线性分析表明……”
+ 要点：把“统计显著性 + 注释富集 + 基因树/同源证据 + 表达/功能证据” 四块拼成因果链条。

```bash
#太好了——下面给你一套针对单个已知基因（以 LFY 为例）在三种不同花序类型的基因组/样本中比对分析的可执行流程。我把流程分成两条主线（有注释基因组 vs. 没有注释的基因组），并提供具体命令、阈值建议、关键产物和如何解读每一步的结果。你只需把数据路径替换成你自己的文件就能跑。

#总体思路（概览）
#目标是回答这些问题：
每个物种/花序类型有没有 LFY 同源（拷贝数）？是单拷贝还是扩增？
序列层面有何差异（编码区突变、indel、domain gain/loss）？
基因结构（exon–intron）是否一致？启动子/调控元件是否差异？
在基因组上的位置及共线性（是否在相同 syntenic block）？
是否有选择信号（Ka/Ks）或功能分化证据？
若有表达数据：表达量是否在不同花序类型中差异？

#下面按步骤给出可复制的操作与解读。
#A. 前处理与准备（适用于所有情况）
#需要文件：
参考 LFY 蛋白序列（查询序列），例如 LFY.fa（蛋白序列优先）。
三个样本的基因组 fasta（genomeA.fa, genomeB.fa, genomeC.fa），以及如果有注释则包含 GFF/GTF（genomeA.gff3 等）。
如果有转录组（RNA-seq）则把清洗后的 FASTQ 或已定量的 TPM/counts 准备好。
建议工具（安装）：DIAMOND/BLAST、MAFFT、IQ-TREE、HMMER、bedtools、samtools、minimap2/exonerate/gmap、gffread、MAKER/Augustus/ BRAKER（若需预测基因）、MCScanX（共线性）、PAML/KaKs_Calculator、MEME Suite、IQ-TREE、TBtools/ggtree。

B. 如果基因组已注释（有蛋白/基因 GFF）
#这是最简单直接的路线。
1) 提取每个基因组的蛋白序列并做同源搜索（查拷贝数）
# 假设你已经有 speciesA.faa, speciesB.faa, speciesC.faa
cat speciesA.faa speciesB.faa speciesC.faa > all_proteins.faa
diamond makedb --in all_proteins.faa -d all_proteins
diamond blastp -q LFY.fa -d all_proteins -o LFY_vs_all.m8 -f 6 qseqid sseqid pident length evalue bitscore --max-target-seqs 500 --evalue 1e-5 -p 8

#筛选：pident ≥ 30% 且 alignment coverage ≥ 50%（对 LFY 这种保守 TF，建议更严格：pident ≥ 50% & coverage ≥ 70%）。
#结果：统计每个物种中匹配到多少个不同基因ID → 拷贝数。
解读：若每个物种为单拷贝，则比较序列差异更可靠；若某物种有多个拷贝，注意可能的功能分化（sub/neofunctionalization）或伪基因。

2) 多序列比对 + 蛋白域注释
#提取所有候选 LFY 蛋白序列做比对与域分析：
# 假设已用脚本把 hits 提取为 LFY_candidates.faa
mafft --auto LFY_candidates.faa > LFY.aln.faa
# 可视化/修剪
trimal -in LFY.aln.faa -out LFY.aln.trim.faa -automated1
# domain scan
hmmscan --domtblout LFY.pfam.domtblout Pfam-A.hmm LFY_candidates.faa
解读：查看 LFY 的保守域（例如 LFY 有特定的 DNA-binding domain 或家族特征）。若某个拷贝缺失关键域，可能是伪基因或功能丧失。
比对里看是否存在插入/缺失（indel）、氨基酸改变集中在功能位点上。

3) 构建家族树（推断duplication与orthology）
iqtree2 -s LFY.aln.trim.faa -m MFP -B 1000 -T 8 -pre LFY_tree
解读：如果同物种内序列形成单独分支 -> 物种特异扩增（可能并非正交）。
查找 duplication 节点时间（可结合物种树校准，或用 Ks 分析估计时间）。

4) 基因结构对比（exon–intron）
使用 GFF 与 gffread 提取 mRNA/CDS，再绘制结构图（TBtools 或自制脚本）：
gffread -x transcripts.fa -g genomeA.fa genomeA.gff3
# 或用 TBtools 的 “Gene Structure View” 可视化
解读：exon 数、长度差异可能影响功能或调控。

5) 启动子 / 上游调控元件差异
提取上游 2 kb（或按情况调整）：
# 需要 bedtools + gene coordinates
bedtools getfasta -fi genomeA.fa -bed LFY_promoters.bed -fo LFY_promoters.fa
# 然后 MEME:
meme LFY_promoters.fa -oc meme_out -dna -nmotifs 8 -minw 6 -maxw 20
解读：比较 motif 是否一致，是否出现特异性 TF binding site（可能解释表达差异）。

6) 共线性 / 基因组位置比较（判断是否在相同 syntenic block）
用 MCScanX 或通过 pairwise BLAST + MCScanX 分析：
若 LFY 在不同物种位于同一 syntenic block（保守位置） → ortholog；若位置差异或在不同 block → 可能重排或局部扩增。
可视化：Circos 或 TBtools synteny plot。
解读：位置保守支持功能保守；若位置改变且伴随拷贝扩增，可能与物种特异表达/功能相关。

7) 选择压力量化（Ka/Ks）
取每对 ortholog CDS（核酸），对齐蛋白后反向翻译到核酸对齐（使用 pal2nal 或 TranslatorX），然后计算 Ka/Ks（PAML yn00 或 KaKs_Calculator）。
# 用 pal2nal:
pal2nal.pl LFY.aln.faa LFY_CDS.fasta -output paml > LFY_paml.aln
# 然后 yn00 或 KaKs_Calculator
KaKs_Calculator -i LFY_paml.aln -o LFY_kaks.txt -m NG
解读：Ka/Ks > 1 提示正选择（需谨慎，单基因证据有限）；Ka/Ks << 1 强烈负选择（保守）。

C. 如果基因组未注释（只有fasta）
在没有注释的情况下，你需要先定位 LFY 基因（可用 tBLASTn / exonerate / genewise）并预测其基因结构。
1) tBLASTn 定位候选基因
```
