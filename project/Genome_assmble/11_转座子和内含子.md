### 11.转座子和内含子
| **特征** | **内含子 (Intron)** | **转座子 (TE)** |
| --- | --- | --- |
| 所在位置 | 基因内部（外显子之间） | 基因组各处（基因内外都有可能） |
| 功能 | 不编码蛋白，调控作用 | 重复扩增，影响基因组结构/进化 |
| 计算方式 | 基于注释文件 exon → 算间距 | 基于 RepeatMasker/EDTA → 注释重复序列 |
| 长度特征 | 通常几百到几千 bp | 差异极大，可几百到几万 bp |
| 生物学意义 | 影响基因剪接、多样性 | 基因组膨胀、基因表达调控、进化动力 |
