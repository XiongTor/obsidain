#### （3）[Allo4D](https://github.com/yuanw-18/Allo4D)亚基因组分型
###### **该分型软件存在很多染色体未划分在两个亚基因组中！！！**
```bash
#路径：新服务器/data/xueqin/Prunus/genome_assembly/1Chromosome/06_polish/14.Allo4D
conda activate Allo4D
##原理：
用异源四倍体和相对二倍体物种之间的共线和进化关系来区分亚基因组。该流程包括四个主要步骤（图2）：
（1）对基因组数据进行比对并获得共线关系。在此过程中，通过古老的复制事件生成的基因被移除。
（2）选择复制的基因对（B. racemosa:4x中有两个副本，B. asiatica:2x中有一个副本），并根据B. asiatica中的基因位置将这些基因块组合成簇；然而，只保留具有五个以上共线基因对的簇。
（3）在簇内构建系统发育树，并根据进化关系确定最佳树。我们将与二倍体成簇的基因定义为SubA基因，其他基因定义为SubB基因。
（4）使用SubA和SubB基因作为标记物划分亚基因组。

##注意：文件命名一定要跟这个一致，sp4、sp2、outgroup
##注意：#Step2:一定要检查sp4_sp2.collinearity.filter.num请确保第三列为二倍体基因，第四列为异源四倍体基因。
##注意：#export PATH=/data/xueqin/software/MCScanX-master:$PATH

#Input data
allotetraploid：sp4.pep;sp4.cds;sp4.bed;sp4.genome.fa
relative diploidy：sp2.pep;sp2.cds;sp2.bed
outgroup：out.pep;out.cds

awk '{print $1, $2, $3, $4}' /data/xueqin/Prunus/genome_assembly/1Chromosome/06_polish/15.WGDI/01.data/DYGY.wgdi.gff>DYGY.bed
awk '{print $1"\t"$2"\t"$3"\t"$4}' DYGY.bed > sp4.bed

awk '{print $1, $2, $3, $4}' /data/xueqin/Prunus/genome_assembly/1Chromosome/06_polish/15.WGDI/01.data/persica.wgdi.gff >persica.bed
awk '{print $1"\t"$2"\t"$3"\t"$4}' persica.bed > sp2.bed

awk '{print $1, $2, $3, $4}' /data/xueqin/Prunus/genome_assembly/1Chromosome/06_polish/15.WGDI/01.data/humilis.wgdi.gff >humilis.bed
awk '{print $1"\t"$2"\t"$3"\t"$4}' humilis.bed > out.bed
其余均是persica.wgdi.pep和persica.wgdi.cds修改成sp2.pep和sp2.cds
#humilis.bed、DYGY.bed、persica.bed均在output文件夹下
#Be careful, bed file is only four columns:
#scaffold gene start end
#R498Chr1.ctg1   indica_OsR498G0100000700.01.T01 17040   23888
#R498Chr1.ctg1   indica_OsR498G0100001000.01.T01 24847   26162

#genome file, pep file and cds file are common fasta format.
ln -s /data/xueqin/Prunus/genome_assembly/1Chromosome/06_polish/03.T2T_polish_3/05.bcftools/T2T-Polish.fa ./sp4.genome.fa

#Step1: Align allotetraploid and diploid genome data and obtain their collinear relationship.
python /data/xueqin/software/Allo4D/script/Allo4Dalign.py -thread 40 \
 -sp4pep sp4.pep -sp2pep sp2.pep \
 -sp4bed sp4.bed -sp2bed sp2.bed \
 -sp4cds sp4.cds
#Output files (You can check in ./1.Collinear/)

#Step2: Select replicated gene pairs and construct clusters.

python /data/xueqin/software/Allo4D/script/Allo4Dcluster.py -kt 0.3 -sp4bed sp4.bed
#Output files (You can check in ./2.Cluster/)
#sp4_sp2.collinearity.filter.num file: Please make sure the diploid gene in the third column, and the allotetraploid gene in the fourth column. If the order is reversed, amend line 45 in Allo4Dcluster.py.

#os.system("paste %s/block_number.txt %s/sp4_sp2.collinearity.filter|awk -v FS='\t' -v OFS='\t' '{print $1,$2,$5,$4}' > %s/sp4_sp2.collinearity.filter.num" % (path2,path2,path2))

python Allo4Dcluster.py -kt 0.3 -sp4bed sp4.bed
```
