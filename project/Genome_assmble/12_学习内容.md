从图中可以看出：

1. **A_genome 和 B_genome 染色体之间存在大量一对一或一对多的同源关系**，说明它们共享祖先基因组。
2. A 和 B 基因组并不是完全独立的，它们之间存在广泛的共线性，提示可能经历过 **全基因组复制（polyploidization）或染色体重排**。
3. 比如 A_genome 的染色体 1、12、13 在 B_genome 中主要对应 10、11、14，说明这几条染色体在进化过程中 **成对地分化**；而像 A_genome 的 2、3、5 在 B_genome 中则对应 4、6、7，也体现了对应关系。

总结：

**生物学原因（真实差异）**

1. **两个基因组进化距离远**
+ 如果 A 与 B 属于 **不同物种**、**亚种**，或是经过了长期独立进化的同属种群，那么：
    - 大量染色体重排、易位、倒位、插入/缺失 会破坏共线性区域。
+ 举例：
    - 异源四倍体或染色体重组丰富的物种间共线性也可能很低。
3. **大规模基因组重排（如全基因组复制后重塑）**
+ 如果某一组基因组是通过染色体重组或**全基因组复制（WGD）**后发生了染色体融合/裂解/易位，那么即使基因内容相似，也可能检测不到共线区。
3. **转座元件活动导致结构变化**
+ 丰富的 **转座子活动** 会打断大片共线区域，制造出假阴性（false negative）共线区。
4. **基因组装质量问题**
+ 如果 A 或 B 的组装：
    - **碎片化（scaffold太短）**
    - **错配**（misassembly）
    - 染色体未完全拼接（未达chromosome-level）
+ 那么 SYRI 无法正确比对或识别大型连续共线区域。
5. **比对文件 delta 质量差**
+ `nucmer` / `mummer` 生成的 `.delta` 文件是共线分析的基础。
    - 若参数设置过严或过松（如最小匹配过短），可能丢失了真正的共线段。
    - 低质量比对将使 SYRI 误判变异而非识别共线。

---

6. **SYRI 参数过于保守或输入不合适**
+ SYRI 默认对共线段要求比较严格（例如对连续、方向一致性等）。
+ 如果你输入的是未过滤的 `delta` 或 genome 预处理不充分，SYRI 可能会更倾向于标记为结构变异而非共线。

# 假设 genes.gff3

模块 D — 差异表达与偏向分析（Panel D 火山图）

思路：把对应的 homeolog pairs（geneA, geneB）在样品中比较表达，统计 log2FoldChange 与显著性（DESeq2 或 limma）。常用方法：把两个拷贝视为两个条件计算差异（若样品足够可重复），或者用成对 t-test（注意统计模型要合理）。

R 脚本（示例用 DESeq2 对成对样本比较）DE_bias_panelD.R：

library(DESeq2)
library(ggplot2)
library(data.table)

counts <- fread("expression_counts.tsv", data.table=F)
rownames(counts) <- counts[,1]; counts <- counts[,-1]
meta <- fread("sample_metadata.tsv")

# Suppose you have columns subgenome and you want to compare expression of A copies vs B copies across tissues:
homeologs <- fread("homeolog_pairs.tsv", header=F)
colnames(homeologs) <- c("geneA","geneB")

# Create pseudo-samples: sum/aggregate for geneA and geneB? 
# Simpler approach: for each pair compute log2 ratio across samples and perform statistical test across replicates
res_list <- list()
for(i in 1:nrow(homeologs)){
  a <- as.numeric(counts[homeologs$geneA[i], ])
  b <- as.numeric(counts[homeologs$geneB[i], ])
  # compute log2 ratio per sample (add pseudocount)
  l2r <- log2((a+1)/(b+1))
  # t-test vs 0
  tt <- t.test(l2r)
  res_list[[i]] <- data.frame(geneA=homeologs$geneA[i], geneB=homeologs$geneB[i],
                              log2FC=mean(l2r), pval=tt$p.value)
}
res <- do.call(rbind, res_list)
res$padj <- p.adjust(res$pval, method="BH")
res$neglogp <- -log10(res$padj)
res$group <- ifelse(res$log2FC>0 & res$padj<0.05, "A-biased",
             ifelse(res$log2FC<0 & res$padj<0.05, "B-biased", "balanced"))

# volcano
ggplot(res, aes(x=log2FC, y=neglogp, color=group)) +
  geom_point(alpha=0.6) + theme_minimal() +
  scale_color_manual(values=c("blue","grey","red")) +
  xlab("log2FoldChange (A/B)") + ylab("-log10(adjusted p-value)") +
  ggsave("panelD_volcano.png", width=6, height=5)


注意：上面示例中用的是对每对基因计算样本内的 log2 ratio 并 t 检验是否偏离 0，适合样本数较多且组织可重复的情况；若你有实验设计（对照/处理），建议用更严格的模型（DESeq2 设计矩阵）进行推断。

library(data.table)
library(ggplot2)

counts <- fread("expression_counts.tsv")
rownames(counts) <- counts[[1]]; counts <- counts[,-1]
# normalize (TPM or z-score)
mat <- as.matrix(counts)
# log transform and z-score per gene
mat_log <- log2(mat + 1)
mat_z <- t(scale(t(mat_log)))

homeologs <- fread("homeolog_pairs.tsv", header=F)
colnames(homeologs) <- c("A","B")
res <- data.frame()
for(i in 1:nrow(homeologs)){
  a <- homeologs$A[i]; b <- homeologs$B[i]
  if(!(a %in% rownames(mat_z) && b %in% rownames(mat_z))) next
  vecA <- mat_z[a,]; vecB <- mat_z[b,]
  corv <- cor(vecA, vecB, method="pearson")
  distv <- dist(rbind(vecA, vecB), method="euclidean")
  res <- rbind(res, data.frame(A=a,B=b,cor=corv,euclid=as.numeric(distv)))
}
# quadrant counts
ggplot(res, aes(x=cor, y=euclid)) +
  geom_point(alpha=0.5) +
  geom_vline(xintercept=0) + geom_hline(yintercept=median(res$euclid)) +
  ggsave("panelF_corr_euclid.png", width=6, height=5)
