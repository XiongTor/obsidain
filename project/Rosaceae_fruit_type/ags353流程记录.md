## 3. 数据处理

### 3.1 数据整合

使用自编脚本 `hybpiper_paftol_combine.sh` 将 Paftol 数据与 HybPiper 数据合并：

```bash
iqtree -s trimal/7628.tri.fasta -m MFP -B 1000 --bnni -T 10 -pre ./genetrees/7628.tri
```

数据使用原则:
- 优先使用自己筛选的 HybPiper 353 基因
- 若筛选基因数 < 300，可用 Paftol 数据替换（需该物种在 Paftol 中存在）

### 3.2 问题排查

#### 问题1: 4个基因建树失败

| 基因编号 | 问题物种 | 问题描述 |
|----------|----------|----------|
| 4691 | *Sorbus aucuparia* | 序列全为"N" |
| 5449 | *Rhaphiolepis ferruginea* | 序列全为"N" |
| 7021 | *Alniaria alnifolia*, *Griffitharia hemsleyi*, *Kageneckia oblonga* | 序列全为"N" |
| 7361 | *Chaenomeles speciosa* | 序列全为"N" |

原因分析: 加入 Paftol 数据后，序列修剪时删除了原有信息位点，导致部分物种序列变为全"N"。

解决方案: 去除上述问题物种

## 4. 关键发现

1. Paftol 数据整合风险: 跨数据库整合可能导致序列质量问题
2. 数据质量检查必要性: 建树前需检查序列完整性（避免全"N"序列）
3. 数据库错误可能性: 公共数据库数据可能存在分类标注错误

---

## 5. 后续建议

- 建立数据质量检查流程（自动检测全"N"序列）
- 对比 Paftol 与 HybPiper 数据差异
- 记录数据版本信息，便于追溯
